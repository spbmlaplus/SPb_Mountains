# Замена Google Maps на собственные растровые карты

> **Статус (2026-05-15).** Это исходный документ-«почему». Конкретный план для этого репозитория — в `migration-implementation-plan.md`, текущее состояние — в `HANDOFF.md`. По факту фазы 1 и 2 уже выполнены: тайлы лежат на `https://pashteto.github.io/gavr-tiles/relief/{z}/{x}/{y}.png`. Движок выбран **MapLibre GL JS**, а не Leaflet — потому что в проекте уже ~80 GeoJSON-слоёв на API `addSource`/`addLayer`, и переписывать их под Leaflet дороже, чем поменять `mapbox-gl` на `maplibre-gl` (API совместим). Хостинг — GitHub Pages, не S3/R2: после реальных измерений размер ~234 MB, CDN избыточен. Этот файл оставлен как контекст и идеологическая база.

Краткая инструкция по миграции `Map-View-Client` с Google Maps на собственный базовый слой из растровых файлов с сохранением функционала зума и слоёв.

## Принцип

Веб-карты не грузят гигантский растр целиком. Картинка нарезается на **тайлы 256×256** для каждого уровня зума — пирамида XYZ-тайлов. Браузер тянет только видимые. Это ровно то, что делает Google, и ровно то, что умеют open-source движки.

Задача делится на три шага: георефернс растров → нарезка в тайлы → замена движка карты.

## Шаг 1. Геопривязка растров (если нужна)

Если файлы — обычные PNG/JPEG/TIFF без географии, привязываем в **QGIS** (бесплатный):

1. Открыть растр через плагин *Georeferencer*.
2. Поставить 4–10 контрольных точек с известными координатами (углы, перекрёстки, вершины).
3. Целевая система координат — **EPSG:3857** (Web Mercator).
4. Сохранить как **GeoTIFF**.

Если уже GeoTIFF с привязкой — пропускаем.

## Шаг 2. Нарезка в тайлы

Стандарт — **GDAL** (`brew install gdal` / `apt install gdal-bin`):

```bash
gdal2tiles.py --zoom=10-18 --xyz --processes=8 input.tif ./tiles
```

На выходе — `tiles/{z}/{x}/{y}.png`. Кладётся как статика на S3 / Cloudflare R2 / любой CDN. Бэкенд не нужен.

Альтернативы: **MapTiler Engine** (GUI), **QGIS → Generate XYZ Tiles**, **titiler/rio-tiler** (тайлы на лету из COG).

Диапазон зума выбираем разумно: 10–17 покрывает локальную туристическую карту. Чем уже — тем меньше места (от сотен МБ до десятков ГБ).

## Шаг 3. Замена Google Maps в коде

Рекомендация — **Leaflet**. Лёгкий, API похож на Google Maps, миграция занимает часы.

```js
const map = L.map('map').setView([44.5, 41.0], 12);

L.tileLayer('https://cdn.example.com/tiles/{z}/{x}/{y}.png', {
  minZoom: 10,
  maxZoom: 18,
  attribution: '© Горные просторы',
}).addTo(map);

// Слои поверх — переносятся 1:1
L.geoJSON(routesData, { style: ... }).addTo(map);
L.marker([44.51, 41.02]).addTo(map);
```

Альтернативы: **MapLibre GL JS** (WebGL, плавный zoom, тяжелее) — если в перспективе много векторных данных. **OpenLayers** — если нужны нестандартные проекции.

## Шаг 4. Слои сверху

Всё, что сейчас отрисовано поверх Google, переезжает без изменений:

- GeoJSON / маркеры / полигоны → `L.geoJSON`, `L.marker`, `L.polygon`.
- Прозрачные тематические оверлеи → второй `L.tileLayer` с PNG.
- Переключатель видимости → встроенный `L.control.layers(baseLayers, overlays)`.

Замена `setMap(map)` / `setMap(null)` у Google → `addLayer` / `removeLayer` у Leaflet.

## Чек-лист перед стартом

- [ ] Растры геопривязаны (проверить наложением на OSM в QGIS — должны совпасть).
- [ ] Решён диапазон зума (10–17 — типовой).
- [ ] Выбран хостинг тайлов (GitHub Pages не подходит при объёме > 1 ГБ — берём S3 / R2 / GCS + CDN).
- [ ] На бакете включён публичный доступ и CORS: `Access-Control-Allow-Origin: *`.
- [ ] Все слои поверх — в EPSG:4326 или 3857 (иначе сместятся).
- [ ] Атрибуция растра в углу карты (юридически и по стилю).

## Минимальный план работ

1. Собрать растры → проверить привязку в QGIS.
2. Прогнать `gdal2tiles.py`, нужный диапазон зума.
3. Залить `tiles/` на S3/R2, открыть публичный доступ + CORS.
4. В `Map-View-Client` заменить инициализацию Google Maps на Leaflet, переписать слои.
5. Тест на мобильном, на крайних масштабах, на медленной сети.

## Оценка трудозатрат

- Геопривязка одного растра в QGIS — **30–60 мин**.
- Нарезка `gdal2tiles` — от минут до часов (зависит от площади и зума).
- Миграция кода Google Maps → Leaflet в типовом проекте — **1–2 рабочих дня**.
- Заливка на CDN и настройка CORS — **1–2 часа**.
