## Как посмотреть локально (важно)

Production **не содержит** этих правок. Dev-серверы **падают** между сессиями — не полагаться на старые порты.

### Рекомендуемый способ — preview собранной версии

```powershell
cd C:\Work\SPb_Mountains\SPb_Mountains
$env:VITE_TILE_BASE_URL="https://spbmlaplus.github.io/spb_mountains_tiles"
$env:VITE_BASE_PATH="/"
npm run build
npx vite preview --host 0.0.0.0 --port 4173
```

Открыть: **http://localhost:4173/**

С телефона в той же сети: `http://<LAN-IP>:4173/` (последний раз был `192.168.0.102`).

### Dev (hot reload)

```powershell
cd C:\Work\SPb_Mountains\SPb_Mountains
$env:VITE_TILE_BASE_URL="https://spbmlaplus.github.io/spb_mountains_tiles"
$env:VITE_BASE_PATH="/"
npm run dev -- --host 0.0.0.0 --port 5180
```

Открыть: **http://localhost:5180/**

### Частые ошибки

| URL | Проблема |
|-----|----------|
| `https://spbmlaplus.github.io/SPb_Mountains/` | Старая версия без QA-правок |
| `localhost:5176` / `5180` после перезагрузки ПК | Сервер уже не запущен |
| `localhost:4173/SPb_Mountains/` при `VITE_BASE_PATH=/` | Неверный путь — белый экран |
| Dev без `VITE_BASE_PATH=/` | Нужен путь `/SPb_Mountains/` |

Для production-сборки в CI: `VITE_BASE_PATH=/SPb_Mountains/` (см. `.github/workflows/deploy.yml`).
