## Запуск preview

```powershell
cd C:\Work\SPb_Mountains\SPb_Mountains
$env:VITE_TILE_BASE_URL="https://spbmlaplus.github.io/spb_mountains_tiles"
$env:VITE_BASE_PATH="/"
npm run build
npx vite preview --host 0.0.0.0 --port 4173
```

Открыть: **http://localhost:4173/**

### Dev (hot reload)

```powershell
cd C:\Work\SPb_Mountains\SPb_Mountains
$env:VITE_TILE_BASE_URL="https://spbmlaplus.github.io/spb_mountains_tiles"
$env:VITE_BASE_PATH="/"
npm run dev -- --host 0.0.0.0 --port 5180
```

Открыть: **http://localhost:5180/**

## Частые ошибки

| URL | Проблема |
|-----|----------|
| `localhost:4173/SPb_Mountains/` при `VITE_BASE_PATH=/` | Белый экран — нужен корень `/` |
| `localhost:5173` / `5180` после перезагрузки ПК | Сервер не запущен — пересобрать и запустить preview |
| GitHub Pages без push | На production нет незакоммиченных правок |

## Быстрый чеклист

- [ ] Открывается http://localhost:4173/
- [ ] Кнопка слоёв — квадрат с иконкой, не круг
- [ ] Панель с картинками и **подписями**, не только текст
- [ ] **Desktop:** лента превью-карт вверху лонгрида (над первым абзацем)
- [ ] Выбор карты меняет слои на карте
- [ ] Амфитеатр → подменю с 5 пунктами
- [ ] Старт лонгрида с начала, id_map=1
- [ ] **«Исследовать горы»** — только базовая карта (id_map=1), без маршрутов и точек обзора
- [ ] **Мяки и Сельки** (id_map=13) — подписи из поля `name` слоя maki_selki
- [ ] Подписи к фото — italic, серые, без мигания при скролле
- [ ] Финальный абзац — текст не «дёргается» между элементами
